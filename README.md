# ContextRoute AI

**Intelligent Routes. Safer Journeys.**

India-first context-aware route recommendation and road-safety Android application.

## Approved baseline
- Native Android application
- Kotlin, Jetpack Compose, Material 3
- Minimum Android API 31
- Local-first persistence: Room and DataStore
- Guest-first; no login, signup, OTP, or mandatory account
- Foreground location only; no background tracking in the MVP
- English-only initial interface
- No microphone, voice, speaker, or audio features
